把每個動作的 PNG 圖片放進這個資料夾，檔名要和動作 id 一致。
系統會自動對應：動作 id「streamline-plank」→ 讀取 /exercises/streamline-plank.png
找不到檔案時，畫面會自動顯示該動作的 emoji 圖標（不會壞掉）。

【內建動作需要的 PNG 檔名】
  cat-cow.png            貓狗式（暖身）
  dead-bug.png           死蟲式（暖身）
  bird-dog.png           鳥狗式（暖身）
  streamline-plank.png   流線型棒式（核心）
  side-plank-rotation.png 側棒式轉體（核心）
  superman-flutter.png   趴姿超人打腿（核心）
  bear-plank-taps.png    熊爬定住＋拍肩（核心）
  hollow-hold.png        船身撐體（核心）
  cobra-stretch.png      眼鏡蛇式伸展（伸展）
  child-pose.png         嬰兒式（伸展）

【自訂動作】
  在 App 裡新增／編輯動作時，於「動作圖片檔名」欄位填入你放在這裡的檔名
  （例如 my-move.png），即可對應。

建議：正方形圖片、每張 < 500KB，PNG 或 WebP 皆可（副檔名自行對應）。
休息預告畫面會以較大尺寸顯示這張圖，動作進行中則以小縮圖顯示。
